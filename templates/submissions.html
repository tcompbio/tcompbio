TCB Submission Instructions

We use the reviewing and publication system of OpenReview for openness and transparency: https://openreview.net/group?id=TCB

Before submitting to TCB, please carefully read the Submission Guidelines and Editorial Policies, which explains TCB's scope, novelty requirements, code requirements, and review process. Also read the Author Guidelines, the Code of Conduct, and the Ethics Guidelines.

TCB requires that all submissions include source code. Please ensure your code is packaged and uploaded before submitting. See the Code Requirement section of the Author Guidelines for details.

TCB uses a single-blind review process. You do not need to anonymize your submission.

Once your manuscript is correctly formatted and you have read the TCB requirements (in particular the novelty and code requirements, the policy on dual submissions, and the ethics guidelines), proceed to the OpenReview TCB site to begin the submission process.

You will receive an email once your submission has been made, asking you to recommend potential Action Editors appropriate for your submission.
